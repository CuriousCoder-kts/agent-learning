## 三、核心知识点（务必理解，不背）

### 1. 消息角色（messages）
- `system`：给模型的**全局人设与规则**，优先级最高。客服 Agent 的"身份"就写在这。
- `user`：用户输入。
- `assistant`：模型的回复。**历史 assistant 消息 = 模型记着的对话**。
- 后续 W2 会用到 `tool` 角色（工具执行结果）。

> 多轮对话的本质：每次调用都把**完整历史**塞进 messages 一起发出去。
> 模型本身是"无记忆"的——所谓记忆，是你每次帮它带上。

### 2. temperature
- `0`：稳定、可复现，适合结构化任务、工具决策。
- `0.7`：日常对话默认。
- `1+`：发散、有创意，适合文案。
> Agent 的"决策节点"一律用低温，否则行为不可预测。

### 3. 结构化输出
- 目的：让模型的输出**可被程序解析**，这是 Agent 能"自主行动"的前提。
- 手段：prompt 约束 +（可选）`response_format`。
- 必须配 **兜底**：解析失败要有降级策略（重试 / 转人工）。
